# astrbot_plugin_japan_livecam (日本实况街景) 🗾

基于 [Mini Tokyo 3D](https://minitokyo3d.com/) 与实时摄像源的 AstrBot 插件。可以在 QQ 群/私聊中直接查看日本东京、羽田机场、成田机场、涩谷、新宿、富士山等 65+ 个地标的**实时高清现场画面与街景**。

---

## ✨ 特性

- 📸 **65+ 日本实况机位覆盖**：收录羽田机场、成田机场、涩谷十字路口、新宿歌舞伎町、秋叶原、东京站、彩虹大桥、富士山河口湖、江之电镰仓高校前等核心场景。
- 🔍 **超清画质优先（1080P/720P）**：内置智能画质优选机制，优先拉取 1080P Full HD 超高清画面，确保停机坪飞机涂装、交通街景细节分明。
- 🤖 **LLM Agent 自然语言集成**：接入 `@filter.llm_tool`，用户在聊天中随意发送“*想看看目前东京羽田机场的画面*”、“*帮我看下涩谷十字路口现在人多不多*”，大模型即可自动感知并调用返回实况大图。
- ⚡ **快捷指令支持**：支持 `/livecam <地点>`（如 `/livecam 羽田机场`）与 `/livecam list` 机位列表。
- 🚫 **无油管链接泄露**：不输出外部视频源链接，仅展示清晰现场图与 Mini Tokyo 3D 官方三维机位视角。
- 📦 **零额外繁重依赖**：无需安装庞大的浏览器驱动或本地转码库，开箱即用，高可用防风控。

---

## 🚀 安装方法

### 方式一：克隆到 AstrBot 插件目录（推荐）

进入你的 AstrBot 项目目录下的 `data/plugins/`：

```bash
cd AstrBot/data/plugins
git clone https://github.com/Anon2Tokyo/astrbot_plugin_japan_livecam.git
```

在 AstrBot WebUI 插件面板中点击 **「重载插件」** 或重启 AstrBot 即可。

---

## 💬 使用示例

### 1. 自然语言交互 (LLM Agent)
无需输入特定格式指令，直接在 QQ 对话：
* `“想看看目前东京羽田机场的画面”`
* `“现在涩谷街头下雨了吗？调个画面看看”`
* `“看下富士山现在能不能看见”`

### 2. 快捷指令
* `/livecam 羽田机场`：直接调取羽田机场第 2 航站楼实时停机坪画面。
* `/livecam 涩谷`：查看涩谷十字路口实况。
* `/livecam 富士山`：查看河口湖富士山景观机位。
* `/livecam` 或 `/livecam list`：获取支持的热门地点分类列表。
